## 🆘 Support Resources

| Issue | Solution |
|-------|----------|
| **Can't start app** | Make sure Python 3.8+ installed, dependencies in requirements.txt |
| **Port already in use** | Use `--server.port 8505` or kill process on 8504 |
| **Backend not connecting** | Ensure FastAPI backend running at http://127.0.0.1:8000 |
| **Data not saving** | Check `data/` folder exists and has write permissions |
| **Features not working** | Check backend logs, see README.md troubleshooting |
